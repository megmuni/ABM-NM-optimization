# Setting up a connection to Github on ComputeCanada

**Prerequisites**

- A Github account

> Note: If a Github repository you are cloning is set to private, the owner of that repository needs to add your Github account as a collaborator.

**Collaboration workflow**

1. You will create a private repository in your own directory (i.e. in your home directory).
2. You can pull/push changes to the remote repository, or create branches for testing changes.

**Instructions for setup**

1. You first need to set your Git identity to match that of your actual Github account. On the server, run:

```bash
git config --global --edit
```

This will open a file in your text editor. Change the name and email field to match your profile on Github. To access your name and email, log into Github and go to **Account**.

https://github.com/settings/profile

> Note: If you set the email associated with your web-based Git actions to be private, you can use the `no-reply` email generated by Github. Otherwise, just use your primary email address.

2. Verify that your config has been set appropriately by entering:

```bash
git config user.name
git config user.email
```

3. Now, you will need to set up SSH authentication. If you are prompted to enter a username or password when entering commands like `git push origin` then your SSH authentication has not been properly set up.

On the server, enter:

```bash
ssh-keygen -t ed25519 -C [GITHUB EMAIL]
```

4. Press enter when the prompt opens up if you want to use the default location to store your SSH key (recommended). The location is accessible by `~/.ssh/id_ed25519`. If you previously had a key here, it will be overwritten.

A passphrase is optional.

5. Get the SSH key by entering:

```bash
cat ~/.ssh/id_ed25519
```

and copy the output.

6. Now, you need to add this key to Github. Visit https://github.com/settings/keys and click on **New SSH key**. Enter the information for your new key.

7. Back on the server, you now want to set up SSH-agent forwarding so your credentials are automatically used when performing actions. Open the file at `~/.ssh/config` for editing. If it does not exist, create it by `touch ~/.ssh/config`.

Enter the following text into the file:

```
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519
```

8. Perform this command to ensure that you have properly registered your SSH key:

```bash
ssh -T git@github.com
```

This should output something like:

```
Hi [username]! You've successfully authenticated, but Github does not provide shell access.
```

9. You should be able to perform actions like merging/pulling. Clone the repository using the SSH option:

```
git clone git@github.com:mintary/abm-opt.git
```

10. Create a branch, i.e.

```
git checkout -b "my-branch"
```
